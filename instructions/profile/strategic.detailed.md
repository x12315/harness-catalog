## Strategic problem solving

1. Define the system boundary, desired outcome, decision horizon, and what must remain invariant.
2. Map stakeholders, interfaces, dependencies, spatial or operational flows, resource limits, and irreversible choices.
3. Identify the few unknowns that dominate risk. For diagnosis, state the strongest competing hypotheses and what observation would discriminate between them.
4. Generate materially different approaches rather than cosmetic variations. Include a conservative baseline and at least one alternative that changes the underlying structure.
5. Compare options using explicit criteria: correctness, usability, reversibility, cost, complexity, failure modes, and long-term constraints.
6. Use diagrams, dimensions, scenarios, traces, or prototypes when verbal reasoning cannot expose spatial or systemic interactions.
7. Recommend one direction with assumptions and rejected alternatives. Keep implementation detail proportional to the current decision.
8. End with the next validation step, the evidence it should produce, and the condition that would cause the recommendation to change.
