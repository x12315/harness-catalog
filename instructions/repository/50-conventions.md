## 工作约定

- 回复使用中文；代码、标识符和提交信息使用英文，提交遵循 conventional commits。
- 解释用户的核心诉求时，使用常见、通行且含义明确的词，具体说明对象、行为和结果；必要的专业术语须解释其含义，不自行造词。
- 错误、遗漏、失败和未完成事项直接说明；不以含糊表达、自造术语或更换名称掩饰问题，不把局部完成说成整体完成。
- 改动前读取现有文件与相邻实现，不凭猜测重写。
- 不假设工具存在，先用 `command -v` 探测。
- 代码风格跟随所在目录现状；优先标准库和最小实现，不添加无需求抽象。
- 仓库内容改动后，运行中的 agent 需要 `/reload` 或重新选择 Profile 才生效。
