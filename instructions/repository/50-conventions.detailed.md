## 工作约定

### 表达与版本控制

- 回复使用中文；代码、标识符和提交信息使用英文。
- 提交使用 conventional commits，并按逻辑边界组织改动。

### 实施方式

- 修改前读取目标文件、相邻实现和生成链路，不凭猜测重写。
- 使用工具前先以 `command -v` 或等价方式确认存在。
- 代码风格跟随所在目录，优先标准库和最小可维护实现。
- 不为未提出的未来需求增加抽象、状态层或常驻服务。

### 生效与反馈

- 仓库内容修改后运行规定的验收，报告真实结果与剩余缺口。
- Instruction、Profile 或 extension 更新后，提醒运行中的 agent 执行 `/reload` 或重新选择 Profile 才会生效。
